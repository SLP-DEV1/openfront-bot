# OpenFront AggroBot v1.21.5 — First Public Preview

The first public preview of **OpenFront AggroBot**, an experimental Tampermonkey automation project for [OpenFront](https://openfront.io/).

AggroBot brings expansion, economy, combat, naval planning, diplomacy, defense and research-oriented neural strategies into a single configurable bot.

## Highlights

- **Automated expansion & resource management:** territorial growth, building priorities, upgrades and troop reserve decisions.
- **Combat and defense:** target evaluation, naval logistics, defensive investment and threat-aware planning.
- **Diplomacy & local Duo coordination:** optional two-browser teamwork using a localhost relay.
- **Experimental neural strategy:** a separate Impossible Run3 variant with a fixed, bundled Schema 4 model.
- **Visibility & research tooling:** an in-game control panel, diagnostics, a read-only local monitor and reproducible benchmark tools.

## Download and install

Choose **one** of the two userscripts attached to this release:

| Asset | Description |
| --- | --- |
| `OpenFront_Solo_AggroBot.user.js` | Standard browser automation bot with configurable strategy |
| `OpenFront_AggroBot_Impossible_Run3.user.js` | Experimental neural Run3 variant with a bundled champion model |

1. Install [Tampermonkey](https://www.tampermonkey.net/) in your browser.
2. Download your preferred `.user.js` file from **Assets** below, then open it in Tampermonkey to install it. If your browser downloads rather than imports it, create a new Tampermonkey script and paste in the complete file contents.
3. Open [openfront.io](https://openfront.io/) and enter a playable match.
4. Use the AggroBot panel. Press **Alt + Shift + P** to pause/resume, or **Alt + Shift + X** to disable.

**Only run one AggroBot variant at a time.** Node.js is not required for the normal userscript; it is used for optional local tooling.

For setup help and development notes, see the [README](https://github.com/SLP-DEV1/openfront-bot#readme).

## Preview status & known limitations

**This is an experimental pre-release, not a stable or guaranteed-winning bot.**

- The official-engine smoke test has passed, but the broader regression suite still contains known failing strategy tests involving economic and defensive priorities. See [GitHub Actions](https://github.com/SLP-DEV1/openfront-bot/actions) for current results.
- Neural policies and scripted benchmarks do **not** establish a reliable win rate against human opponents or at Impossible difficulty.
- Changes to the OpenFront game can affect automation behavior. Follow OpenFront's rules and terms; automation in online games may be restricted.
- The project is independent and is **not affiliated with or endorsed by OpenFront**.
