# OpenFront AggroBot v1.21.6 — English UI & OpenFront Compatibility Preview

This experimental update brings an **English control panel**, refreshed official-engine integration for development and important regression fixes.

## What's new

- **English-language interface:** translated menu sections, module toggles, Duo panel, manual strategy labels, tooltips, diagnostics and common gameplay status messages. Saved strategy preferences and internal configuration keys are preserved.
- **Economic planning fix:** optional proactive SAM coverage no longer interrupts productive City/Factory expansion, port investments or the first missile silo **without an observed nuclear threat**. Confirmed enemy missile silos and inbound nukes remain eligible for defensive prioritization.
- **Current OpenFront engine compatibility:** the offline benchmark harness now supports the upstream October 2026 engine package split and new map-file API while preserving historical pinned-engine scenarios.
- **Regression coverage:** all 325 strategy tests pass, alongside successful OpenFront integration and the full GitHub verification workflow on the previous patch. Benchmark behavior does not establish actual success against human players.
- **Cleanup:** removed the remaining sender code for the obsolete localhost monitor.

## Download / install

Download **one** of the two attached files:

- **`OpenFront_Solo_AggroBot.user.js`** — standard AggroBot
- **`OpenFront_AggroBot_Impossible_Run3.user.js`** — experimental variant with the embedded Run3 Schema 4 model

Install using [Tampermonkey](https://www.tampermonkey.net/). If direct file importing does not work, open a new Tampermonkey userscript and paste the entire downloaded file. Only enable one AggroBot variant at a time.

Use **Alt + Shift + P** to pause/resume and **Alt + Shift + X** for emergency stop. For advanced setup see the [README](https://github.com/SLP-DEV1/openfront-bot#readme).
