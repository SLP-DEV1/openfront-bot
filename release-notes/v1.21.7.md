# OpenFront AggroBot v1.21.7 — Stability & Monitoring

This pre-release includes the fixes merged after v1.21.6 and a small browser performance optimization.

## What's fixed
- Correctly count real OpenFront team victory tuples that include the winning client IDs (benchmark outcomes).
- Isolate local Duo pairs by the official GameView match identifier rather than shared game configuration.
- Avoid mixed-language UI text caused by replacing fragments inside other words.
- Protect asynchronous timers against unhandled rejections and enforce the existing emergency-stop policy.
- Avoid unnecessary full-panel DOM replacements when displayed content has not changed.

## Testing
- Expanded regression coverage for official WinUpdate team results, Duo match identity, English UI and timer failures.
- Existing deterministic engine and strategy tests must pass before release.
- A separate scheduled workflow checks the newest upstream OpenFront commit daily; the pinned reproducible workflow remains unchanged.

## Notes
- Run **only one** AggroBot userscript at a time.
- Experimental neural models and engine smokes do not demonstrate competitive multiplayer win rates.
- No automatic deployment of strategy or neural model changes is performed.
